Field Flow (synthetic local runtime)
Usage:
  field-flow [--lang en-US|zh-CN] --help
  field-flow state init --synthetic --mode dry_run|execute --state-dir NEW_DIR --instance-id ID
  field-flow state inspect --state-dir DIR
  field-flow run --config FILE --state-dir DIR [--execute]
Run requires an explicitly initialized state directory. Stop with SIGINT or SIGTERM.
