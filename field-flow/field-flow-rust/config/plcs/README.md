# PLC files

[中文](README.zh-CN.md)

One closed ff.plc JSON object per PLC, schema_version=1 independently of main YAML v2 and SQLite schema1. [s7-a.json](s7-a.json)/[s7-b.json](s7-b.json) are fixed synthetic S7 examples; [modbus-example.json](modbus-example.json) validates declarations only and cannot run. Its34502 port is not a fixture endpoint. Follow the [catalog tutorial](../../USER_GUIDE.md#catalog-v2).

JSON is UTF-8 without BOM; reject duplicate/unknown keys, explicit null defaults, implicit types, float/exponent integer lexemes and nesting beyond16. Main≤64KiB,1–4 unique relative non-symlink paths; each PLC≤1MiB,total≤4MiB,≤4096 points,≤64 DBs or4 tables. IDs are ASCII letters/digits/_/- of1–64 bytes. All declarations including disabled/unreferenced entries are validated. Duplicate device/point identity, physical overlap and shared host:port fail. Shared Modbus Unit IDs on a gateway are not independent transports (shared_transport_unsupported).

Required common fields: format/schema_version/id/protocol/source/connection and exactly dbs for s7 or tables for modbus_tcp. Optional name/display_name/description limits128/256/1024 UTF-8 bytes; metadata only brand/model/firmware≤128. Point descriptions name/display_name/source_name/source_path/source_native_type are optional nonempty strings with limits128/256/256/1024/32. IDs/addresses select points, never labels, brand or filenames.

S7 connection requires canonical unicast IPv4, port1–65535, rack0–7, slot0–31. Optional local_tsap/remote_tsap1–65535 default to256 and256+rack×32+slot. Nondefault TSAP is structurally valid but runtime_compatible=false/run exit2. DB number1–65535,size_bytes2–65536,enabled defaults true,points nonempty; each point requires id/data_type=int16/byte_offset0–65534 and optional enabled. offset+2≤size. INT is signed16-bit big-endian. BOOL/bit/scale/word_order are not S7 v1 fields. Declared size is not proof of field layout/write permission.

Modbus connection requires host/port/unit_id1–255 only. Tables are coils/discrete_inputs/holding_registers/input_registers; point pdu_address is zero-based, never automatically converted from40001. Every functions object requires read/write (write may be null). Coils bool:1/null-or5; discrete bool:2/null; holding int16/uint16:3/null-or6; input int16/uint16:4/null. Register int32/uint32/float32 occupy two registers, require high_word_first/low_word_first and null write. Other types/FC15/16/width/quantity are rejected; end address≤65536, no overlap. Bool/16-bit reject word_order. Optional register scale requires finite factor/offset with absolute value≤1e9 and nonzero factor; bool rejects scale. These declarations implement no Modbus wire/client/codec/write permission.

Manual source requires kind=manual and optional note≤512. DS source requires kind=device_simulator, export_mode=saved_revision, instance_id=device id, revision{id=lowercase UUID,saved_seq=1..9007199254740991,payload_sha256=64 lowercase hex}, nonempty exporter_version≤64 and generated_at RFC3339+08:00. Optional runtime_observation requires observed_at+08,selected_revision,loaded_revision; the last two are revision objects or explicit null. Omit missing observations; saved/selected/loaded are distinct. FF validates declarations and hashes, not DS database truth. DS currently has no exporter; reachable connect host and TSAP directions need explicit future DS confirmation. Source data, original revision payload hash and frozen JSON byte hash are provenance, not effect identity.

Main v2 contains instance_id/plc_files/plc_runtime/flows/http/shutdown_timeout_ms. Each plc_runtime has device_id and the unchanged five budgets. All file IDs require exactly one budget. Flow id/business_name/interval_ms/device_ids are required; demo01 additionally source_id/get_url/input_max_age_ms/target{device_id,point_id}; read_points instead reads1–16 unique enabled references in its subset. No fake HTTP/target fields for readers. Budget ranges and startup rules are in the [guide](../../USER_GUIDE.md); configuration validation is read-only, format-valid incompatibility exits0 while run rejects before state open.
