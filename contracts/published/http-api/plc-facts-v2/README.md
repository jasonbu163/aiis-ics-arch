# PLC facts v2 source contract

Each `POST /api/v1/integration/plc-facts/samples` submits one complete DB sample from one instance and PLC. A request carries at most 512 points and 524288 bytes of UTF-8 JSON. Live delivery and backfill use the same endpoint. DAA freezes the body locally and retries the same bytes. History and per-point latest values commit in one transaction before a `committed` receipt is returned.

The frozen original [OpenAPI](openapi.json), [JSON Schema](schema.json) and [vectors](vectors.json) describe the previous provider. The new [r2 OpenAPI](openapi-acquisition-r2.json), [r2 request schema](schema-acquisition-r2.json) and [r2 vectors](vectors-acquisition-r2.json) describe the current source contract. After authentication, registered `daa` senders must provide nonempty `groupId` and `configRevision`; registered `external` senders may independently omit them or send null. The server derives `sourceType`; requests cannot set it. The same sample identity with omitted fields and then explicit null has different bytes and conflicts. See [ARCH-ACQ-003 r2](../../../../plans/ARCH-ACQ-003-acquisition-data-optional-filters/spec.md).

Each machine instance uses its own Bearer credential. The backend stores its SHA-256 digest and checks the permitted PLC, DB and current generation. A first commit returns `outcome: created`. The same identity and body return `outcome: duplicate` within the effective retention window. Identity or sequence conflicts return 409. An expired sample returns 410 `plc_facts_v2.expired_unconfirmed`. An uncertain commit returns 503 `plc_facts_v2.commit_outcome_unknown`, so the sender retains and retries the frozen sample.

The `/api/v1/acquisition-data/options`, `latest`, `latest/browse`, `history` and `history/{id}` read operations require login, `plc-facts-read` and a role-specific PLC/DB scope. Browse and history may omit PLC or DB, intersect authorization before pagination, and return 50 rows by default with 100 at most. Latest also accepts an exact `pointId`. History uses a Shanghai half-open interval of at most seven days. Historical `sourceType`, `groupId` and `configRevision` can now be null; strict previous readers must adapt. Sample IDs are decimal strings. Raw values expire 24 hours before three calendar months from each observation. See the [maintenance CLI](../../../../backend/scripts/plc_facts_maintenance/README.md).

The module registry declares internal names under `plc_facts.v2.*`. HTTP `errorCode` values use the `plc_facts_v2.*` names fixed by this contract. The source contract awaits isolated verification, target adoption and DAA integration.

REAL uses validated decimal numeric text inside the v2 database JSON fields. Reads restore a JSON number, retaining input precision, negative zero and scientific notation.
