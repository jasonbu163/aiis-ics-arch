# 计划与实绩交互手册

[English](generic-plan-performance-guide.md)

本手册依据通用任务 v2 和当前页面整理，适用于计划、实绩的配置和手工模拟。实际环境以已部署版本、管理员启用的字段和目标 OpenAPI 为准。

## 1. 先看流程

```text
管理员设置字段
       ↓
MES 或人工创建计划（taskNo）
       ↓
CA/FF 或第三方查询新计划，自行决定如何处理
       ↓
SMA 或第三方上报同号实绩
       ↓
后端保存实绩，并将允许回写的共享字段及生产状态更新到同号计划
```

本手册中的“模拟 SMA”指用 Swagger 手工发送相同格式的请求，不表示已连接 SMA 或真实 PLC。计划和实绩只提供任务查询与存储，不判断 CA/FF 有没有向 PLC 下发成功。

## 2. 页面入口与权限

使用拥有相应页面权限的账号登录。管理员可以修改字段配置；计划的新增和修改还需要计划管理权限，实绩人工编辑也受账号权限和字段设置控制。

| 要做什么 | 入口 | 范围 |
| --- | --- | --- |
| 查看、创建和修改计划 | 计划管理 → 计划列表 | 计划 |
| 查看实绩和人工反馈 | 实绩管理 → 实绩列表 | 实绩 |
| 设置计划本地字段 | 计划管理侧栏 → 本地字段管理 | 仅计划 |
| 设置实绩本地字段 | 实绩管理侧栏 → 本地字段管理 | 仅实绩 |
| 设置共享字段 | 任一模块侧栏 → 共享字段管理 | 同一个独立页面、同一份配置 |

页面分为标题与操作、查询条件、列表与分页三部分。可以按任务号、目标、生产状态和创建时间查询；创建时间起点包含、终点不包含。表格过宽时横向滚动，拖动表头边界可调整列宽；每张表的恢复列宽只调整本机显示。创建、更新、采样时间的含义可看标题旁的问号提示。

人工建计划时，在计划列表点击“新建计划”，填写任务号及需要提交的可编辑字段后保存。点击列表行或“详情”查看单条；能编辑的字段按账号权限、字段组和编辑开关决定。实绩列表没有人工新建实绩按钮，生产信息由实绩集成接口创建或更新；已有实绩可在有权限时编辑人工字段和备注。

## 3. 字段分组和容量

每一组最多 100 个槽位，槽位从 1 到 100。

| 字段组 | 数据出现位置 | 示例 |
| --- | --- | --- |
| 计划本地 | 仅计划 | 客户订单号 |
| 实绩本地 | 仅实绩 | 当前速度 |
| 共享 | 计划和实绩 | 产品编码、目标长度、已生产长度 |

共享的是字段定义。计划和实绩仍各自保存该任务的值；只有共享字段允许回写且满足本次写入规则时，实绩才把相应字段更新到计划。共享字段可以从两个侧栏入口管理，保存的是同一份配置。

后端分别用 `plan_main` 和 `performance_main` 保存计划和实绩，每张主表各有 `local_values`、`sync_values` 两个 JSON 值列。字段键、双语名称、类型和开关等定义由 `task_field_definitions` 及相关配置版本记录管理；使用记录用于删除保护。业务接口通过任务号查找和同步，不需要用户直接操作这些数据库表。

字段有一个稳定字段键，例如 `productCode`，供 API 的 `items` 使用。中文名与英文名供页面显示。稳定键以小写英文字母开头，后续允许英文字母、数字和下划线，最长 64 字符；`taskNo`、`productionStatus`、`items` 等系统保留键不能用作自定义字段。同一模块的共享键和本地键不能重名，停用或隐藏也不例外。保存过的字段不能直接修改键、槽位、类型或单位；需要不同含义时，新建字段。

类型包括：字符串（最多 255 个 Unicode 字符）、数值（整数部分最多 10 位、小数部分最多 4 位）和布尔（`true` / `false`）。`0`、`false`、空字符串都不是缺失值。

同一 `taskNo` 在各自模块中标识一条计划或实绩。任务号去除首尾空格并转换为大写，长度为 1–50 字符，可使用英文字母、数字、连字符、下划线和点。同号计划与实绩各自保存；没有同号计划时也可以先保存实绩。

固定生产状态包括 `new`（新建）、`running`（生产中）、`completed`（已完成）和 `error`（异常）。该状态不是可停用的自定义字段；计划和实绩分别保存，集成上报实绩时会同步到同号计划。

## 4. 设置表中的选项

| 设置 | 作用 |
| --- | --- |
| 稳定字段键、槽位、类型 | 标识该字段并约束值的类型；新增时填写。 |
| 中文名称、英文名称、单位 | 页面显示名称及单位；单位可不填。 |
| 启用 | 开启后参与当前配置的读取和允许的写入；停用不删除历史值。 |
| 可清空 | 允许显式提交 `null` 清空已保存的值；未提交字段仍保持原值。 |
| 计划可编辑 | 是否允许有计划编辑权限的登录用户在页面编辑该字段；不是 MES 集成接口的开关。 |
| 实绩可编辑 | 人工归属的字段是否可由有权限的登录用户编辑。 |
| 计划可见、实绩可见 | 控制该模块列表是否显示此列，不等同于读写权限。 |
| 计划列顺序、实绩列顺序 | 设置动态字段在对应列表里的顺序；不填时按槽位。 |
| 回写计划 | 仅共享字段适用；实绩提交该字段后，按当前规则把值回写同号计划。 |

实绩归属决定谁填写：**订单快照**在首次创建同号实绩时，从已有计划复制该共享字段，计划之后的修改不会自动更新已有实绩快照；**自动**由实绩集成接口上报；**人工**由具备权限的登录用户填写。订单快照不能勾选回写；非人工归属不能勾选实绩可编辑。计划本地字段没有实绩归属。

共享字段主表可按稳定键或任一语言的名称搜索，也可筛选启用状态和实绩归属。默认每页 20 条，表头选择框只选择当前页。翻页保留勾选，重新查询或重置筛选会清空勾选。行内“编辑”打开当前字段，“批量编辑”打开选中的字段。主表和批量编辑表分别记忆本机列宽。

共享字段的新增和编辑弹窗在点击“保存”前保留草稿，取消或关闭会丢弃草稿。从计划管理或实绩管理侧栏分别进入独立的本地字段管理页，使用相同的编辑流程。提示配置修订冲突时，保留当前草稿供核对。

设置页的“字段版本”表示当前字段定义版本，“配置修订号”用于保存或删除时发现其他人的并发修改；这两个数字不需要手工更改。收到修订冲突后可先记录未保存的内容，取消或离开后重新读取、核对，再决定如何修改。集成请求可选的 `fieldConfigVersion` 只是附带信息，不能用来切换当前配置。

## 5. 手动新增一个可删除的测试字段

本例只做字段设置和查看，不创建或更新任务。若已有其他程序可能在测试期间写入计划或实绩，先协调测试时间。

1. 管理员打开任一模块的“共享字段管理”。
2. 点击“新增字段”，保留系统选择的空槽位。
3. 稳定字段键填 `tryScratch19`（如果已存在，请换一个未占用的键）；中文名填“临时测试”；英文名填 `Temporary test`；类型选“字符串”；实绩归属选“人工”。
4. 勾选“启用”“计划可见”“实绩可见”，然后点击“保存”。本例不需要勾选“回写计划”或编辑开关。
5. 打开计划列表和实绩列表，必要时横向滚动，确认都能看到“临时测试”列。已有任务未填值时显示 `—`。只读查看不产生使用记录。
6. 返回共享字段管理，在该行的“操作”中点击“删除”并确认。删除已保存字段在确认后立即执行，无需再点击底部“保存”。成功后该行消失，槽位可重新使用。
7. 再点击“新增字段”检查槽位，然后取消新增弹窗。

实际能否删除以后端检查结果为准：一旦计划或实绩按包含该字段的配置创建或有效更新，即便本字段没有填值、处于停用状态，或某次 POST 没有改变原值，也算使用。历史下发批次也可能构成使用。只读 GET 和查看页面不构成使用。若提示“字段已有历史引用或使用证据不完整，可改为停用”，不要尝试强制删除。

批量删除当前组字段时，勾选目标并打开“批量删除”，核对确认弹窗列出的字段。任一字段受保护时整批都不删除。收到保存或删除结果未明的提示时，先核对页面重新读取的配置，再决定是否重试。计划和实绩各自通过侧栏的“本地字段管理”进入。返回时恢复列表偏好并重新读取字段配置。

## 6. 停用、恢复和槽位

如果字段已经使用、无法确认是否使用，或暂时不想继续使用：

1. 打开相应字段管理，找到该字段。
2. 取消勾选“启用”，点击“保存”。停用后普通 GET 不输出该字段，当前写入、继承和回写也不再使用它；历史值保留。
3. 如需恢复原字段，重新勾选“启用”并保存。相同字段原有的值会重新显示。

停用不释放槽位，不能把它改成另一个字段。只有后端确认从未使用、管理员成功删除的字段才能释放槽位。删除前还要核对 MES、SMA 等外部映射；本系统不能自动发现全部外部调用方。

若要体验“已用字段不能删除”，请另建一个测试字段，再创建或更新测试任务后尝试删除。该字段按当前规则会继续占用槽位，之后只能停用。不要拿现有业务字段做该测试。

## 7. 通过 Swagger 模拟 MES、CA/FF 和实绩上报

### 7.1 准备

在本机开发环境可打开 `http://127.0.0.1:8000/docs`；其他环境应使用该环境实际的后端地址。以下 `/api/v1/integration/...` 是第三方集成入口，不需要前端登录 Bearer；字段管理页面和人工编辑仍需要登录及相应权限。

选择未使用的测试任务号。测试会在当前目标库创建或更新记录，普通任务接口不提供测试单删除功能。不要把示例任务号当成已经存在；先分别用计划和实绩的按任务号 GET 查询，均确认不存在后再继续；若任一记录已存在就换一个号，并在后续请求中一致替换。

以下完整示例假设管理员已经配置并启用这些字段；先查询 `GET /api/v1/integration/task-field-configs?module=plan` 和 `module=performance`，确认键名、类型和归属。不要为了运行例子改动现有业务字段：

| 字段键 | 分组与类型 | 用途 |
| --- | --- | --- |
| `productCode` | 共享、字符串、订单快照 | 计划产品编码 |
| `targetLength` | 共享、数值、订单快照 | 计划目标长度 |
| `customerOrderNo` | 计划本地、字符串 | 客户订单号 |
| `completedLength` | 共享、数值、自动，开启回写计划 | 实绩已生产长度 |
| `currentSpeed` | 实绩本地、数值、自动 | 实绩速度 |

### 7.2 MES 创建 A 单

在 Swagger 展开 `POST /api/v1/integration/plans/upsert`，点击“Try it out”，将请求体替换为以下 JSON，点击“Execute”：

```json
{
  "taskNo": "GUIDE-A-001",
  "items": {
    "productCode": "PRODUCT-A",
    "targetLength": 120,
    "customerOrderNo": "MES-A-001"
  }
}
```

首次创建时若没有同号实绩且未提交状态，计划为 `new`。在 Swagger 的响应正文中，`data.outcome: created` 表示新建；`updated` 表示已有记录发生变化，`unchanged` 表示业务值未变。若同号已存在，该接口会更新提交字段，所以先查询任务号是否可用。

在计划列表按任务号查询，也可以点击“详情”核对产品编码、目标长度和客户订单号。若列表缺少某列，请检查该字段的计划可见开关并横向滚动。

### 7.3 CA/FF 查询新单

在 `GET /api/v1/integration/plans` 中点击“Try it out”，将 `productionStatus` 设为 `new`，点击“Execute”后在响应 `data.items` 中查找 A；也可用 `GET /api/v1/integration/plans/by-task/{taskNo}` 查看 A。该 GET 是查询，不代表领取或 PLC 下发。

### 7.4 模拟 SMA 或第三方上报 A

在 `POST /api/v1/integration/performances/upsert` 提交：

```json
{
  "taskNo": "GUIDE-A-001",
  "items": {
    "completedLength": 45,
    "currentSpeed": 0
  }
}
```

新建实绩省略状态时为 `running`。检查响应正文中的 `data.performance` 与 `data.planSync`，并重新查询计划和实绩：`completedLength` 按开关回写计划；`currentSpeed` 是实绩本地字段，只出现在实绩。没有传真实采样时间时，最近采样时间显示 `—`。

在实绩列表按任务号查询，可看到“有计划”为“是”，并在详情中核对字段。计划侧则显示回写后的已生产长度。未配置可见的字段可在详情或对应按任务号 GET 的 `items` 中核对。

### 7.5 完工和部分更新

同一个接口可以只提交本次要修改的固定字段。例如：

```json
{
  "taskNo": "GUIDE-A-001",
  "productionStatus": "completed"
}
```

成功后实绩和同号计划状态均为 `completed`，已保存的长度和速度保留。再次发送同号请求只合并本次提供的字段；显式传 `null` 仅在该字段允许清空时生效。新单的默认状态不意味着已存在实绩在省略状态时会自动改为 `running`。

`producerId`、`targetKey`、`fieldConfigVersion`、`observationSeq` 和 `observedAt` 按合同可省略；不知道目标时留空，不自动分配产线。真实采样时间已知时再传有时区的 `observedAt`，不要用请求时间冒充。自动采集字段本次上报未提供采样时间时，最近采样时间变为缺失。时间 API 返回 `+08:00`，页面显示上海时间到秒。

`createdAt` 是记录创建时间；`updatedAt` 只在该记录实际变化时更新；`lastObservedAt` 是最近一次采集上报提供的采样时间，不是页面刷新时间。仅提交状态且没有提交 `observedAt` 时，原有最近采样时间保留。

以实际成功处理顺序更新。`observationSeq` 和采样时间不作为去重或顺序裁决：迟到的有效请求仍可能覆盖较新的值或状态；状态 `completed` 之后再次上报有效 `running` 也会覆盖。返回 `task.commit_unknown` 表示提交结果未知，应先按任务号 GET 对账，再决定是否重发。

## 8. 没有计划时上报和补建

实绩可以没有同号计划，列表“有计划”会显示“否”，实绩仍正常保存。之后可以在有权限且拥有计划页面权限的实绩详情进入“补建计划”。默认不复制历史实绩共享反馈；如确需一次回填，可勾选“一次性从同号实绩回填允许回写的共享值”。后续有效实绩上报仍按当前回写开关处理。

若想单独模拟这个情况，先确保计划和实绩均没有 `GUIDE-B-001`，再向实绩接口发送：

```json
{
  "taskNo": "GUIDE-B-001",
  "items": {"completedLength": 20, "currentSpeed": 0}
}
```

查询 B 的实绩，预期 `hasPlan` 为 `false`，`planSync` 的 `outcome` 为 `skipped`，原因是 `no_plan`。随后可在实绩详情补建计划，或向计划接口提交下面的独立请求，显式选择一次性回填：

```json
{
  "taskNo": "GUIDE-B-001",
  "backfillExisting": true
}
```

重查两边，B 的计划会继承实绩当前状态，并回填允许回写的 `completedLength`。这一请求没有提供产品编码或目标长度；已有实绩的订单快照也不会因为后来补建计划自动重建。仅当测试库允许保留 B 单时执行。

## 9. 常见问题

- **新列看不到：** 检查字段是否启用、对应模块“可见”是否勾选，刷新列表并横向滚动。
- **字段不能删除：** 可能已有任务或历史批次使用、使用证据不完整，或仍有可识别的引用；按提示停用并核对外部映射。
- **提交被拒绝：** 检查键名、启用、类型、实绩归属和清空开关；一个非法字段会使整包失败。
- **冲突或不可用：** 配置修订过期、已知目标不一致或字段被使用可能返回 `409`；无效字段或类型可能返回 `422`。收到 `503 task.commit_unknown` 时先查单对账；其他服务不可用错误按实际提示处理。
- **两个模块的值不同：** 共享配置相同不代表值天然相同；确认实绩本次提交了该字段，且共享项开启回写，计划存在同号任务。
- **SMA 不能启动投递：** 当前 SMA 配置阶段仍以保存配置和纯预览为主，自动投递与实际联调有独立任务和验收边界。

正式 API 细节以目标环境 `/docs` 和[通用任务 v2 合同候选](../contracts/published/http-api/generic-task-workflow-v2/README.zh-CN.md)为准；[字段设置简要说明](../frontend-js/FIELD_SETTINGS_GUIDE.zh-CN.md)可作为速查。[历史讨论稿](generic-task-workflow-discussion.zh-CN.md)可能保留旧方案，不能作为当前行为操作指南。计划和实绩的验证、最终验收与真实设备联调状态分别见[任务记录](../plans/ARCH-TASK-001-generic-plan-performance/checklist.md)；当前手册不替代验收。
