# 计划与实绩字段设置使用说明

本说明适用于通用计划和实绩页面的“字段设置”。字段配置由管理员维护；列表可见、人工编辑及接口调用仍受各自权限和任务状态约束。字段设置决定业务字段的含义和行为，不会自行修改 PLC 点位或接入程序。

## 从哪里操作

1. 以管理员身份进入“计划管理”或“实绩管理”，点击标题右侧的“字段设置”。弹窗顶部显示当前**字段版本**和**配置修订号**。
2. 每行是一项字段定义。左右滚动可查看全部设置，拖动表头边界可调整列宽；桌面上的稳定字段键固定在左侧，便于辨认当前行，窄屏时随表格滚动以留出操作空间。点击“恢复此表列宽”只重置当前入口的弹窗列宽，不改变字段草稿或主列表的列宽。计划和实绩弹窗分别保存本机偏好。
3. 点击“新增字段”增加一条本机草稿。它默认选择当前页面的本地组及下一个可用本地槽位，也可在保存前改选共享组和未占用的槽位。填写稳定字段键、类型和中英文名称等信息后，点击“保存”才提交。
4. 新增但**尚未保存**的行可点击该行稳定字段键下方的“移除草稿”。已保存字段没有物理删除按钮；要退出新任务使用，取消该行“启用”并保存。关闭或取消弹窗时，未提交的编辑会按原有方式保留为当前浏览器本机草稿；成功保存后清除该草稿。

草稿与服务器配置的版本或修订号不一致时，重新打开会读取当前配置；请重新核对再修改。保存时如提示配置已被别人修改，先重新读取，避免覆盖他人的变更。

## 字段组与基本信息

| 设置 | 说明 |
| --- | --- |
| 字段组 | **共享**供计划和实绩使用；**本地**只属于当前入口的计划本地组或实绩本地组。两入口读取同一组共享定义，但各自只显示自己的本地组。 |
| 槽位 | 每组各有 1–100 号。保存过的槽位即使停用也继续占用，不可分配给另一个字段。 |
| 稳定字段键 | API 中使用的英文键，以小写英文字母开头，后续使用英文字母、数字或下划线；同一模块内不能与共享组重名。它不是可随意更改的显示标题。 |
| 类型 | 字符串、数值或布尔。字符串最多 255 个 Unicode 字符；数值整数部分最多 10 位、小数部分最多 4 位；布尔值为 `true` 或 `false`。 |
| 中文名称 / 英文名称 | 两种界面的显示标题，均须填写。它们不是 API 键。 |
| 单位 | 可选的显示和业务含义，例如 `m`。 |
| 实绩归属 | 决定实绩值来自订单快照、自动来源还是人工填写；具体见下节。计划本地字段没有实绩归属。 |
| 列顺序 | 当前入口列表的显示顺序，允许整数 0–65535，较小的排在前面。清空后显示“按槽位”，按该字段的槽位作为默认顺序；计划和实绩分别设置。 |

保存过的字段不能直接修改稳定字段键、类型或单位含义。需要改变时，先与使用方确认兼容方案，使用**新的字段键和未占用槽位**创建替代项，再按需要停用旧项；不要把旧槽位当作新字段复用。

## 每个勾选项

| 勾选项 | 作用与限制 |
| --- | --- |
| 启用 | 决定该版本是否使用此字段。取消并保存会发布新的业务版本；旧任务仍按其绑定版本解释和处理字段。 |
| 可清空 | 允许有权写入的调用方显式提交 `null`，移除已保存的该字段值；但目标的 PLC 下发映射若要求该字段有值，计划仍不能将它清空。`0`、`false` 和空字符串各自是值，不等同于清空。 |
| 回写计划 | 仅共享组中实绩归属为“自动”或“人工”的反馈字段可开启；开启后计划侧不能同时勾选“计划可编辑”。符合条件的实绩值会回写到同任务计划。 |
| 计划可编辑 | 允许 MES 下单/改单及有权限的人员在计划表单中编辑该计划字段；它不会绕过调用来源、任务状态或角色限制。实绩本地字段不能开启。 |
| 实绩可编辑 | 允许具备权限的人从实绩入口填写该字段；只有实绩归属为“人工”时可开启。计划本地字段不能开启。 |
| 计划可见 / 实绩可见 | 控制相应列表默认显示该字段；计划入口配置计划可见，实绩入口配置实绩可见。隐藏列不等于停用字段，也不删除数据。 |

计划本地字段不能设置实绩归属、实绩可编辑、实绩可见或回写；实绩本地字段不能设置计划可编辑、计划可见或回写。共享字段的勾选组合也受上述归属和写入规则校验，组合不合法时保存会被拒绝。

## 三种实绩归属

- **订单快照**：用于共享的订单字段。首次建立实绩时，从同号计划复制兼容的订单值作为实绩快照；不能作为人工实绩反馈或开启回写。没有计划时快照可为空。
- **自动**：由目标登记的自动来源提交，例如 SMA 或 CA / Field Flow。该来源每次上报须包含其负责且启用的完整自动字段集。共享反馈可按规则开启回写；实绩本地自动值不会回写计划。
- **人工**：由有权限的人填写实绩值；还须勾选“实绩可编辑”才能在人工入口编辑。共享人工反馈可按规则开启回写。

实绩本地字段只允许“自动”或“人工”；“订单快照”适用于共享订单字段。一个任务使用其目标和绑定版本登记的自动来源，界面选择归属不会自动建立或切换来源。

## 保存、停用与版本

字段版本用于固定任务的业务规则，配置修订号用于管理员并发保存检查。新增字段、启用/停用、写入归属或回写规则变化会发布新业务版本；仅修改中英文名称、相应列表可见性或列顺序只推进配置修订号，并将这些显示设置叠加到历史版本。完全没有变化的保存保持原版本和修订号。

例如，将共享反馈字段的“启用”取消并保存后，新任务使用新版本，不再按该版本使用它；已有任务仍按原绑定版本处理。旧版本的数据不会因此被删除，旧任务也可能使该字段继续出现在当前页的历史版本列中。要恢复同一字段，重新勾选该行“启用”并保存；它继续使用原键和原槽位。

“列顺序”和“列表可见”是管理员保存的显示设置；鼠标拖动的列宽是当前浏览器的个人偏好，不进入业务配置版本。弹窗的“恢复此表列宽”只恢复弹窗列宽，列表页面各有自己的恢复入口。

## 与 PLC、采集和接入方一起变更

字段设置会影响调用合同，但不会自动修改项目映射或现场程序。修改或停用之前，请按项目流程与负责 MES、PLC 下发、CA / Field Flow、DAA 和 SMA 的人员核对：

1. **先核对下发映射。** 目标和字段版本的项目映射会列出 PLC 下发所需字段。被列为下发参数的字段须在该版本启用、允许计划编辑且有值；如果直接停用或改为回写字段，新的计划创建或领取可能被拒绝。即使第三方集成入口关闭，人工新建计划仍按已登记的目标版本检查必填下发参数。
2. **为新版本准备目标映射。** 发布新业务版本前后要按项目批准的配置流程准备并加载相应目标版本、下发字段、PLC 序号上限和自动来源；不要覆盖仍被旧任务使用的版本映射或旧自动流。旧任务继续使用旧版本，新任务使用生效版本。
3. **同步采集到实绩的转换。** DAA 保存的是采集事实；SMA 或项目指定的 CA / Field Flow 自动流负责将事实按任务号、绑定版本和字段键组织为完整快照。新增、停用或改变自动归属字段时，调用方也必须使用对应版本的启用字段集合，否则上报会被拒绝。界面勾选不会自动创建点位映射、修改客户端或证明现场联调完成。
4. **核对实际生效结果。** 在获准的测试范围中，先读取字段版本和目标登记，再用合成计划、领取和同号实绩验证；确认现场接入方准备就绪后，按项目批准的操作流程切换。

接口字段、调用样例和详细版本约定见[通用计划与实绩 HTTP 合同](../contracts/published/http-api/generic-task-workflow-v1/README.zh-CN.md)。
